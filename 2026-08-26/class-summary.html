Week 2 · Class 04 · 2026-08-26

0826 课堂总结

Identity, Migration & Belonging · Synonyms and thematic vocabulary

本节完成的内容

  • 先用叙事语境复习 Week 1 的 Choice, Risk and Responsibility 词汇。重点再次区分 disregard 是动词，negligence 是名词；同时复习 foreseeable / predictable、repercussion、mitigate / alleviate、rectify、remorse 和 integrity。
  • 讨论 identity 的组成：personality and characteristics、cultural / ethnic / family background，以及 beliefs。做 SSAT 阅读时，identity 往往与家庭、文化和群体归属同时出现。
  • 区分 immigration（迁入另一国家的过程或制度）、immigrant（人）与范围更广的 migration（迁移）。
  • 学习并辨析 heritage、displacement、diaspora 和 alienation：它们分别强调传承、被迫离开后的失落、离散群体，以及人与群体之间的疏离。
  • Synonyms 继续使用 CORE → FORM → FORCE → DECIDE。resilient 的近义方向是 adaptable；alienation 在本题中最接近 estrangement。
  • 重点比较 acclimate / adjust 与 conform：前者强调适应条件，后者强调遵从主流规范。进一步连接 integrate、assimilate 与 preserve 的边界。
  • 通过 The Map in the Hall 把词汇放回段落链：displacement / heritage / diaspora → alienation / marginalization → shared project → acclimate / integrate versus assimilate → cohesion and resilience。

课堂表现

  • 对 belonging 和 identity 的核心概念有较好的直觉理解，也愿意参与讨论和尝试回答。
  • 能够说出 resilient 的核心方向并选出 adaptable；遇到不完全熟悉的词时，能够利用五个选项进行排除。
  • 新词朗读清楚；此前读错的部分词汇已有进步。
  • 下一步要从“在选项中认出答案”继续提升到“脱离选项也能独立定义、比较近义词边界，并用完整句解释理由”。
  • 词汇与阅读判断仍容易依赖直觉。回答时继续写出或说出 CORE、词义边界和具体语境证据。

复习与下一步

  • 每天用短时间复习新词：definition、synonym、antonym 和一条例句一起记，不只记中文。
  • 继续完成已经布置的 Poetry Reading Q1–Q20；本次课堂没有新增 Class 04 作业。
  • 对作业页面或材料位置有疑问时，及时通过 WeChat 提问。
  • 下次课会用新的复习文本再次调用今天的词，并加入相关 Reading questions；今天尚未进入 Analogies。
