Class 00

Reading Structure、Synonyms 与 Analogies

本节课完成内容

课堂内容已经完成，下面可以用于课后回看。

  1. Reading：从整篇结构判断答案。练习 paragraph job、main purpose、sentence function，并用原文 evidence 限制选项。
  2. Synonyms：先确定核心词义。结合词性、语气、强弱和排除法判断最接近的意思。
  3. Analogies：先说完整关系句。确认两个词之间的 connector 和方向，再把同一关系代入选项。

课堂练习记录
