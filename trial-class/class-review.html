Class 00

把已经会的方法固定下来，再集中修复不稳定的步骤。

已经做得好的地方

  1. 遇到生词不会立即停止。可以继续结合 context 与 elimination 判断。
  2. 能识别基础词语关系。part-to-whole 等常见关系已经有初步意识。
  3. 能抓住文章整体方向。main purpose 判断表现较好，并能在提示后理解 hook、theme word 等概念。

接下来优先巩固

  1. Reading：每段先写一个简短的 job。分清 main point、supporting detail 与 example，避免从第一句开始逐句翻译。
  2. Sentence Function：回答“这句话为什么出现在这里”。判断它是在提出问题、解释、举例、转折，还是给出结果。
  3. Analogies：补全 A → B → C 的逻辑链。先写具体 connector，再检查方向，不从 A 直接跳到 C。
  4. Vocabulary：持续积累并复习。课堂中的个别正确答案不等于词汇已经稳定；保持规律复习，并把不熟悉的词单独标记。

本次课后任务

两项作业都需要独立完成并提交。
