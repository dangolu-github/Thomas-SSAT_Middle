课堂总结

今天继续完成 From Grievance to Declaration 的 Session 2，重点从复述内容进入结构分析：同一段文字既有在文章中的作用，也可能包含事件发展中的一个阶段。

我们用四段阅读作了对照：第一段交代 grievances 与最初回应；第二段解释从寻求 reconciliation 到考虑 independence 的变化；第三段解释 Declaration 的结构，同时呈现前面变化产生的正式结果；第四段说明文献的 public purpose 与预期影响。

第三段是关键示范：paragraph function 可以是 explaining the document’s structure，event-chain function 可以是 presenting the result。判断题目问的是哪一种，才能选择同一层面的答案。第四段的 sought to 和 more likely 表示目标或可能影响，不能读成已经实现的结果。

文献内部还要分清 introduction、preamble、grievances 和 resolution：先说明为什么需要公开解释，再提出原则，列举证据，最后作出正式决定。它们与阅读文章的四段不是同一组编号。

复习时，每段先概括一句核心意思，再补上作者的动作：introduces、explains、contrasts 或 supports。连事件链时，说明前后发生了什么变化，并保留 some、remained divided、sought 等范围限制。新阅读练习集中检验 paragraph function 与 event-chain function。
