Class summary · 本课重点

主题：Observation, Evidence and Explanation。本课重点放在科学语境词汇、近义词的精确含义，以及 Analogies 中的词性和具体动作。

  • Words for Investigation：specimen, magnify, transparent, distinguish, detect, variable, consistent, infer, tentative, replicate。把词义、词性和例句连起来复习。
  • Word relationships：区分复制一个副本与重复一个过程；理解前缀 re- 后，还要核对整个词的实际意思。
  • Sentence meaning：infer a conclusion from evidence 中，from 引出推断的依据；differentiate A from B 表示把 A 和 B 区分开。
  • Synonyms：Meaning → Form → Nuance → Prediction → Test。先解释词义，再比较选项。
  • Analogies：Meanings → Connector → Order → Test → Limit。用一句具体的英文关系句连接首对，再代入所有选项。

课堂完成位置：Action and Object · Practice 1 — Peel is to orange as。之后的部分转为课后学习与练习。

Feedback · 学习反馈

你愿意尝试解释词义，也会在追问后继续比较选项。课堂讨论已经开始把“词是什么词性”和“动作具体做了什么”结合起来。

接下来要把“认识这个词”推进到“能准确解释并放进句子”。遇到近义词，不要只凭字形、词缀或感觉选择；说清它与最接近选项的差别。遇到 Analogies，先写具体关系句，再判断每一组选项能否保持相同关系和方向。

复习本课十个词时，先读例句，再遮住释义用自己的话解释；特别留意 infer … from …、replicate 与 duplicate，以及一个词的名词、动词用法。

Next step
