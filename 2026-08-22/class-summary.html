Week 1 · Class 02 + Class 03 · 0822 + 0823

课后总结

SSAT Poetry Reading · The Road Not Taken

本节课重点

  • 认识 line、stanza、motif，并用 stanza function 追踪诗歌结构。
  • 先按 punctuation 还原完整句子，再判断换行对 meaning 与 emphasis 的影响。
  • 练习 pronoun tracing：遇到 it、both、them 时回到最近且语法成立的 noun。
  • 使用 smallest-jump inference：Evidence → one small logical bridge → bounded inference。
  • 结合 grassy、wanted wear、about the same，判断两条路的差异并没有最初看起来那么明确。
  • 结合 yet 与 way leads on to way，理解一个选择如何引出后续选择，使返回变得不太可能。
  • 本周错题检查只处理已经正式提交后出现的 wrong / omitted；未提交的练习先完成，再进入复盘。

课堂表现

  • 朗读清楚，pronunciation 与 fluency 表现稳定。
  • 能够理解 Stanza 1 的 literal meaning，并找到 undergrowth、wear 等词的语境线索。
  • 能够跟随问题定位明确事实，并积极参与分析。
  • 面对 abstract meaning 时，需要继续区分 textual evidence 与自己的推测。

下一步重点

  • 用一句话概括每个 stanza 的 function，再连接为 whole-poem theme。
  • 每个 inference 都明确写出对应的 evidence anchor，避免 unsupported jump。
  • 继续练习 Vocabulary in Context、Main Idea / Theme、Inference、Tone 与 Text Structure。
  • 完成 The Road Not Taken Q1–Q10 和 In the Garden Q11–Q20，并在同一答题窗口提交 A–E 选项。
  • 打开本周错题记录，逐项确认已经出现的错因；没有错题记录时不补造项目。
